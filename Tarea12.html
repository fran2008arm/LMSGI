Introducción al Desarrollo Web Moderno

La creación de páginas web se basa en estándares abiertos mantenidos por el W3C. Conocer estos estándares es fundamental para cualquier desarrollador que quiera construir sitios accesibles y compatibles con todos los navegadores.

Dentro del diseño web, el HTML semántico consiste en utilizar cada etiqueta según el significado del contenido que encierra y no solo por su apariencia visual. Si aplicas bien este concepto, realmente notarás una mejora en el posicionamiento y la estructura de tus proyectos.

Como se explica en la guía oficial HTML Living Standard, separar la estructura del diseño facilita el mantenimiento del código a largo plazo. A continuación se muestra un ejemplo de estructura básica con formato fijo: 

<!DOCTYPE html>
<html>
  <body>
    <p>Hola mundo</p>
  </body>
</html>
